# Сценарий защиты и вклад участников

## Перед показом

Из корня проекта выполните команды установки и обучения из README. Откройте презентацию и терминал. Для живого показа запустите:

```bash
python auth_risk.py detect data/demo.csv
```

Каждая строка содержит идентификатор, оценку `score`, порог `threshold`, решение `alert`, пропущенные поля `missing` и локальное объяснение `contrast`. Четыре примера выбраны после теста для иллюстрации результатов. Оценка качества рассчитана по всем 4 320 тестовым событиям.

| Событие | Истина и решение | Что показать |
|---|---|---|
| E18090 | Легитимный вход, сигнала нет | Оценка 0,068692. Поле MFA отсутствует и отражено в `missing`. |
| E20390 | Подозрительный вход, сигнал | Оценка 0,997254. Замена числа недавних ошибок на медиану снижает оценку на 0,0972. |
| E20598 | Легитимный вход, ложный сигнал | Оценка 0,870497. MFA и новый регион дают крупнейшие положительные локальные эффекты. |
| E17653 | Подозрительный вход, пропуск | Оценка 0,869660. Сравнить с предыдущим событием и объяснить роль порога 0,87. |

## Промежуточная демонстрация на 5 минут

| Время | Действие |
|---|---|
| 0:00–0:45 | Объяснить, какую задачу решает детектор и откуда взялись данные. |
| 0:45–1:30 | Показать CSV и объяснить поля счётчика ошибок, региона и MFA. |
| 1:30–3:30 | Запустить детектор. Разобрать E18090, E20390 и одну ошибку. |
| 3:30–4:30 | Открыть матрицу ошибок и сравнить F1 двух моделей. |
| 4:30–5:00 | Объяснить, почему аналитику нужны данные об устройстве и MFA. |
